# Phase6N full-subject canonical pair-member stream candidate v1

## Goal

Replace the representative-only Phase6M member grouping with a
complete, frozen, metadata-only CSC pair-member enumeration for
the accepted subject-9 outer-test workload.

This is an additive prospective development candidate. All existing
scientific protocols, selections, hashes, frozen runtime sources,
clean caches and prior qualification evidence remain unchanged.

## Frozen reconstruction

The exact frozen Phase6K metadata auditor enumerates every retained
subject-9 CSC pair, including stored-window and source-trial parents.

The new subclass preserves the original auditor's selection, source
exposure, omission, compute-stratum, workload and descriptor checks.

Each of the 12 resulting frozen shard descriptors is compared with
its existing Phase6K numerical evidence.

## Model-member expansion

All retained model-independent pairs are expanded over only their
frozen eligible model variants and seeds 42, 123 and 2025.

Every expanded member is sorted using the actual frozen Phase6J
canonical pair-member sort contract.

For every member, the frozen Phase6G request builder creates a
complete pre-forward request, whose identity and temporal/persistence
contracts are checked by the frozen Phase6G validator.

The metadata-only request is immediately summarized into a compact
new Phase6N stream digest; full requests are not written to disk.

The producer-aware Phase6M/Phase6L cache inventory binds each member
to its accepted Phase5M or Phase5R clean-cache identity.

These member streams are reconciled independently with every frozen
Phase6K subject-9 per-shard pair-member and temporal window count.

All 189 previously published Phase6M representative request IDs
must appear inside the complete Phase6N subject-9 enumeration.

## Digest provenance

New Phase6N stream digests are canonical hashes of newly defined
metadata-only tokens. They DO NOT recover or replace the original
historical Phase6E digest serializer or its 12 historical digests.

## Data boundary

The frozen Phase6K metadata census counts source CSV lines to
determine historical source-trial lengths. This process does not
parse sensor sample values or label arrays.

No real sensor fault is applied, no compute fault is injected,
no checkpoint/model is loaded, and no model forward is run.

No CSC artifact or success marker is written.

## Remaining work before CSC execution

The complete subject-9 stream is not full-fleet qualification.
The other 60 subjects and the full 732-shard canonical member
stream still require qualification.

The future execution body also needs actual frozen Phase4H
conditioning, Phase5 fault execution, resource restoration,
output artifact validation, and a separately authorized canary.

The frozen Phase6J execute_shard remains disabled. This new
Phase6N execute_shard is also unconditionally blocked.
